وثائق الـ API

واجهة قراءة فقط (GET) بصيغة JSON، تعمل بدون مفاتيح ولا حاجة لتسجيل الدخول، وتدعم CORS من أي موقع.

1. كل التطبيقات

GET /api/apps.json

يرجع كل التطبيقات مع التصنيفات وعددها.

curl https://easy-hub.vercel.app/api/apps.json

2. تطبيق واحد

GET /api/apps/<slug>.json

يرجع بيانات تطبيق واحد بالمعرّف بتاعه. مثال: /api/apps/quran.json

curl https://easy-hub.vercel.app/api/apps/quran.json

3. الحالة

GET /api/health.json

يرجع status: ok وعدد التطبيقات — مناسب للمراقبة.

شكل الاستجابة

{
  "name": "EASY HUB API",
  "version": "1.0",
  "app": {
    "slug": "quran",
    "name": "المصحف الشريف",
    "cat": "apps",
    "status": "live",
    "url": "https://quran-uthmani.vercel.app",
    "tags": ["PWA", "أوفلاين"]
  }
}

أمثلة كود

جافاسكريبت

const res = await fetch("https://easy-hub.vercel.app/api/apps.json");
const data = await res.json();
console.log(data.count, data.apps.map(a => a.name));

بايثون

import requests
data = requests.get("https://easy-hub.vercel.app/api/apps.json", timeout=20).json()
for app in data["apps"]:
    print(app["slug"], app["url"])

من بوت تليجرام

import requests
apps = requests.get("https://easy-hub.vercel.app/api/apps.json").json()["apps"]
text = "\n".join(f'{a["icon"]} {a["name"]} — {a["url"]}' for a in apps)
